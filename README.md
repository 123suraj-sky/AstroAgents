# 🌌 AstroAgents

A **multi-agent AI scientific discovery system** that investigates astronomical datasets, identifies anomalies, challenges findings, and produces evidence-backed research reports — with every tool call, guardrail decision, and agent trace visible in the UI.

> Give it a scientific question. Watch a team of specialized agents investigate it. Inspect every decision.

---

## What It Does

A researcher submits a question such as:

> *"Find unusual objects in this astronomical dataset and investigate whether they differ significantly from normal objects."*

AstroAgents orchestrates a multi-agent workflow:

```
                     Research Manager
                            │
         ┌──────────────────┼──────────────────┐
         ↓                  ↓                  ↓
  Data Scientist      Astronomy Agent    Literature Agent
         │                  │                  │
     Python Tool        Astro Tools        Search / RAG
         │                  │                  │
         └──────────────────┼──────────────────┘
                            ↓
                    Hypothesis Agent
                            ↓
                      Critic Agent
                            ↓
                    Evaluation Agent
                            ↓
                      Final Report
```

Each agent has a distinct role, its own set of tools, and strict guardrails. The system loops — if the Critic flags insufficient evidence, the Manager can dispatch the Data Scientist again. Agents never just pass text; they maintain a shared `ResearchState` that accumulates observations, anomalies, hypotheses, evidence, and tool results throughout the run.

## Key Features

| Feature | Description |
|---|---|
| **Multi-agent orchestration** | LangGraph-powered workflow with conditional looping — not a linear pipeline |
| **Real tool calling** | Agents call Python (NumPy, Pandas, scikit-learn), astronomy APIs (NASA ADS, MAST), and scientific search — the LLM decides, the tool computes |
| **Scientific guardrails** | Unsupported claims, citation failures, numerical mismatches, and out-of-scope tool calls are caught before they reach the report |
| **Agentic evaluation** | Full trajectory evaluation — task success, tool selection, numerical correctness, evidence quality, safety |
| **LLM observability** | Every LLM call, tool call, token count, latency, retry, and guardrail event is traced via Langfuse + OpenTelemetry |
| **Live research UI** | Watch agents work in real time; inspect any tool call, finding, hypothesis, or critic note |
| **Scientific visualizations** | Scatter plots, histograms, PCA, cluster maps, sky maps — generated by the Data Agent and rendered in the UI |

## Getting Started

### Prerequisites

- Node.js 20+
- Python 3.10+
- Docker + Docker Compose

### 1. Clone and configure

```bash
git clone https://github.com/your-username/AstroAgents.git
cd AstroAgents
cp .env.example .env
# Fill in your API keys in .env
```

### 2. Run with Docker (recommended)

```bash
docker-compose up
```

Frontend → `http://localhost:5173`
Backend API → `http://localhost:8000`
API docs → `http://localhost:8000/docs`

### 3. Run individually

**Frontend**

```bash
cd frontend
npm install
npm run dev
```

**Backend**

```bash
# Activate virtual environment
source .venv/bin/activate        # Linux / macOS
.venv\Scripts\activate           # Windows

cd backend
uvicorn app.main:app --reload
```
